Generate a clean, scalable Prisma schema (schema.prisma) containing the following core entities:
 * User: Fields for id, email, passwordHash, name, mobile, role (OWNER, MANAGER, EXECUTIVE, SUPPORT, CUSTOMER), createdAt.
 * Lead: Fields for id, name, mobile, email, city, serviceRequired, stage (NEW, CONTACTED, SCHEDULED, CONVERTED, COMPLETED), source (HOMEPAGE, CONTACT, CHATBOT, REFERRAL), createdAt.
 * Case: Fields for id (format: CIR-2026-XXXX), customerId, assignedToId, serviceType, currentStatus (DOCUMENTS_SUBMITTED, CASE_REVIEW, DOCUMENTATION_VERIFIED, DISPUTE_SUBMITTED, BUREAU_LENDER_REVIEW, FOLLOW_UP, COMPLETED), progressPercentage, expectedCompletionDate, notes, updatedAt.
 * Document: Fields for id, caseId, name, type (PAN, AADHAAR, CREDIT_REPORT, NOC, CLOSURE_LETTER), fileUrl, status, verifiedAt.
 * Payment: Fields for id, caseId, serviceFee, advancePaid, pendingAmount, paymentStatus (PAID, PARTIAL, PENDING), receiptUrl, agreementUrl.
 * Referral: Fields for id, referrerId, refereeName, refereeMobile, rewardAmount, status (PENDING, APPROVED, PAID).
